# Клиентский сайт demo

## Быстрый запуск на Timeweb Cloud

1. Создайте «Облачный сервер» с Ubuntu, публичным IPv4 и минимум 2 ГБ RAM. Не выбирайте App Platform: локальной базе сайта нужен постоянный Docker volume.
2. Направьте A-запись домена на IPv4 сервера.
3. Загрузите и распакуйте эту папку на сервер, откройте её в SSH.
4. Выполните одну команду:

   sudo bash deploy/timeweb-install.sh ваш-домен.ru

Установщик подготовит .env, при необходимости установит Docker, запустит сайт и покажет адрес кабинета. После появления HTTPS подключите Telegram в разделе «Уведомления» кабинета.

## Универсальный ручной запуск

Скопируйте .env.customer.example в .env, укажите DOMAIN и PUBLIC_ORIGIN, затем выполните docker compose up -d --build. Проверка: https://ваш-домен/api/health. Кабинет: https://ваш-домен/s/demo/admin.

Сайт использует отдельную базу в постоянном volume /data. Не выполняйте docker compose down -v и не переиспользуйте volume для другого клиента. Новый ZIP не переносит и не заменяет действующие записи. Перед обновлением сделайте резервную копию; повторный запуск установщика сохраняет существующий .env и volume.
